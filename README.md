# Wave The Ball — V9.3 Rival Score

Version responsive du prototype Wave The Ball, prioritaire mobile vertical et compatible ordinateur.

## Nouveautés

- Une tentative d’arrachage réussie retire désormais 20 % de vie à Solo.
- La jauge de vie est divisée en cinq segments de 20 %.
- Après un vol, le défenseur attaque le panier au lieu de fuir sans objectif.
- Solo peut poursuivre le porteur et appuyer sur `S` pour récupérer la balle à proximité.
- Si Solo ne récupère pas la balle à temps, l’adversaire termine au panier et gagne des points.
- Un score de match séparé affiche `WTB : BAL`.
- Les paniers de Solo valent 2 points, les tirs lointains 3 points et les dunks 2 points.
- Les paniers adverses valent 2 points et s’additionnent au fil du match.
- Le résultat final affiche victoire WTB, victoire BAL ou match nul.

## Commandes ordinateur

- Flèches : déplacement
- `S` : dribble ou récupération du ballon
- `D` : dash
- `F` : dunk
- `G` : Wave Mode
- `Espace` ou `J` : maintenir puis relâcher pour shooter
- `P` ou `Échap` : pause
- `H` : plein écran
- `M` : son

## Mobile

Utilise le joystick, le bouton `DRIBBLE / RÉCUP`, `DASH`, `DUNK`, `WAVE` et le grand bouton `SHOOT`.

## Déploiement GitHub Pages

1. Place `index.html` à la racine du dépôt.
2. Dans `Settings > Pages`, sélectionne `Deploy from a branch`.
3. Choisis `main` puis `/(root)`.
4. Enregistre et attends la fin du workflow Pages.
