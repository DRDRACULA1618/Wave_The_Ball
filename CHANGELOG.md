# Changelog V8.5.3

## Dribble

Le bras côté ballon n'est plus une construction simplifiée. Il réutilise la texture, les volumes musculaires, les ombres et les contours du bras non-dribbleur afin de préserver la même qualité graphique. Les angles épaule-coude-poignet ont été recalculés sur douze poses cohérentes.

## Jauges

Les jauges de tir et de capacité spéciale partagent désormais le même système visuel 64-bit : coque biseautée, chrome cyan, verre sombre, balayage animé, repères gradués et énergie lumineuse. Le pingouin 64-bit reste l'aiguille active.
